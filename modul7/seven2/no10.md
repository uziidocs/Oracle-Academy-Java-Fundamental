## Menentukan *Access Modifier* Terbaik

### a. *Class* `Employee` yang Mencatat Nama, Alamat, Gaji, dan Nomor Telepon

* ***Access Modifier* Terbaik untuk *Instance Variable*:** **`private`**
* ***Access Modifier* Terbaik untuk *Class* `Employee`:** **`public`**

**Alasan:**
1. **Enkapsulasi dan Keamanan Data (`private`):** Atribut seperti gaji (`salary`), alamat (`address`), dan nomor telepon (`phoneNumber`) bersifat sensitif. Dengan menjadikannya `private`, kode dari luar *class* `Employee` tidak dapat membaca atau mengubah nilai tersebut secara langsung tanpa izin.
2. **Kontrol Validasi melalui *Getter* dan *Setter* (`public`):** Pengubahan data hanya dapat dilakukan melalui *method* `public` (misalnya `setSalary()`), sehingga *programmer* dapat menambahkan logika validasi (contoh: mencegah nilai gaji negatif).

```java
public class Employee {
    // Instance variables menggunakan private demi keamanan & enkapsulasi data
    private String name;
    private String address;
    private double salary;
    private String phoneNumber;

    // Constructor dan getter/setter menggunakan public agar dapat diakses terkontrol
    public double getSalary() {
        return salary;
    }

    public void setSalary(double salary) {
        if (salary >= 0) {
            this.salary = salary;
        }
    }
}
```

### b. *Method* Penjumlahan di dalam *Class* `BasicMath` yang Juga Digunakan di *Class* `Algebra`

* ***Access Modifier* Terbaik:** **`public`** *(atau **`protected`** jika `Algebra` merupakan turunan/subclass dari `BasicMath`)*

**Alasan:**
1. **`public` (Pilihan Utama):** Operasi matematika dasar seperti penjumlahan bersifat umum dan aman untuk diakses dari mana saja. Dengan modifier `public`, *class* `Algebra` dapat memanggil *method* penjumlahan milik `BasicMath` baik saat berada di dalam *package* yang sama maupun di *package* yang berbeda.
2. **`protected` (Alternatif Khusus Pewarisan):** Jika `Algebra` dirancang sebagai *subclass* dari `BasicMath` (`public class Algebra extends BasicMath`) dan pembuat program ingin membatasi agar *method* tersebut hanya dapat diakses oleh *subclass* serta *class* lain dalam *package* yang sama, maka `protected` adalah pilihan yang paling tepat.

```java
public class BasicMath {
    // Menggunakan public agar dapat dipanggil oleh class Algebra dari mana saja
    public double add(double a, double b) {
        return a + b;
    }
}

public class Algebra {
    public void solveEquation() {
        BasicMath math = new BasicMath();
        double hasil = math.add(10, 5); // Memanggil method add() dari BasicMath
        System.out.println("Hasil penjumlahan: " + hasil);
    }
}
```

### Ringkasan Perbandingan *Access Modifier* Java

| *Access Modifier* | *Class* yang Sama | *Package* yang Sama | *Subclass* (*Package* Berbeda) | Seluruh Dunia (*Global*) |
| :--- | :---: | :---: | :---: | :---: |
| **`private`** | Ya | Tidak | Tidak | Tidak |
| ***Default* (tanpa keyword)** | Ya | Ya | Tidak | Tidak |
| **`protected`** | Ya | Ya | Ya | Tidak |
| **`public`** | Ya | Ya | Ya | Ya |
